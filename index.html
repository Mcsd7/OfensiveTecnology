06 / PERGUNTAS

Dúvidas frequentes

Preciso de um computador para usar os projetos?

Os projetos indicados para Android e Termux podem ser usados no celular, mas cada ferramenta possui requisitos próprios. Confira a documentação antes de instalar.

Preciso de root no Android?

O ReaDroid foi desenvolvido para análise de APKs sem exigir root. Para outras ferramentas, confira os requisitos e as limitações descritos em cada projeto.

Onde encontro o código-fonte?

Acesse os links dos projetos ou visite o perfil do desenvolvedor no GitHub para ver os repositórios disponíveis.

Posso usar ferramentas de segurança em qualquer sistema?

Use ferramentas apenas em dispositivos, aplicativos e redes que sejam seus ou para os quais você tenha autorização explícita. Respeite a legislação e a privacidade de terceiros.
